Security Suiteの特長

  • 個人情報を安心・安全に扱える
  • 個人情報の自動検知、自動削除ができる
  • 不正やなりすましを防ぐ
  • PCI DSS認証を取得
  • 01
    Secure Path 個人情報を安心・安全に扱える

    Secure Pathとは、Security Suiteのひとつです。
    Secure Pathの機能を利用すると、WebやLINEでのチャットサポートにおいて、オペレーターが顧客の個人情報を安全に受け取り、本人確認や個人情報に基づいた個別対応を行うことができます。

  • 02
    Secure Alert 個人情報の自動検知、自動削除ができる

    Secure Alertとは、Security Suiteのひとつです。
    例えば、Secure Alertの機能を利用すると、チャット上で検出された個人情報をオペレーターが手動で行わなくてもデータベースから自動削除できるため、作業軽減しながらセキュリティを向上させられます。

  • 03
    Secure MFA 不正やなりすましを防ぐ

    Secure MFA とは Security Suiteのひとつです。
    ログイン認証時に、メールやSMSを使って、二段階認証ステップを挟むことでさらに堅牢なセキュリティ運用が実現できます。認証はオペレーター、一般ユーザーどちらに対しても実施可能です。

  • 04
    最高セキュリティを担保する PCI DSS準拠

    PCI DSSとは、加盟店やサービスプロバイダにおいて、クレジットカード会員データの安全な取扱いを目的として策定された、クレジットカード業界のセキュリティ基準です。PCIDSS遵守では、他の個人情報保護制度と比べ、具体的なセキュリティポリシーの策定が求められます。クラッカー等による不正アクセスからサイトを保護し、サイトの改ざんや悪用、情報盗用などのリスクを低減します。

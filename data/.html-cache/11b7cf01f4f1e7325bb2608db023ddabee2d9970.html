使える人を育てる

人材育成
01

経営者・マネジメント層

マンツーマンコーチ

まずは自分の仕事で体感する。専任コーチと、日々の業務を Codex で一つずつ変えていきます。

  • 自社業務を題材にした個別支援
  • 定期的な相談と振り返り
支援内容の例 ＋
  • 受講者ご自身の PC と実業務で、ChatGPT デスクトップアプリの Codex を動かすところから始めます
  • Local・Worktree・Cloud の使い分け、承認とサンドボックスの考え方を、実際の依頼を通して身につけます
  • 自分の業務向けの AGENTS.md・Skills・定期タスクを一緒に作り、セッションの間はチャットで質問できます
  • 残るもの: 業務向けの AGENTS.md / Skills / 手順集と、試した業務と結果の記録
このサービスを相談する ↗
02

チーム・部署・全社

Codex 法人研修

実践ワークショップで、社内に「Codex で仕事を進められる人」を育てます。

  • 業務別の演習と成果物レビュー
  • 社内で再利用できる手順書
支援内容の例 ＋
  • 環境構築、基本操作、承認とサンドボックスの考え方を、非エンジニアの方にも分かる順番で
  • 自部署の業務を棚卸しして自動化テーマを選び、Skills / MCP 連携まで演習します
  • 成果発表と講師レビュー。期間中はチャットで質問できます。教材は Codex 専用に作ります
  • 残るもの: 受講者ごとの試作、社内共有用の AGENTS.md・Skills の雛形、研修資料
このサービスを相談する ↗

実装・開発
03

業務の整理から定着まで

導入コンサルティング

何を任せるかを見極め、権限・ルールの設計から試行・改善まで伴走します。

  • 対象業務の棚卸しと優先順位
  • 権限・運用ルールの設計と試行
支援内容の例 ＋
  • 対象業務の棚卸しと優先順位付け。データ・接続先・操作権限・担当者の 4 点で利用ルールを整理します
  • ワークスペースの設定方針（ロール、Local / Cloud の許可、管理設定）を助言し、実業務での試行を設計します
  • 試行の振り返りと、運用担当への引き継ぎまで伴走します（設定変更は貴社の管理者が実施）
  • 残るもの: 業務一覧と優先順位、利用ルール、設定方針書、試行結果の記録、運用マニュアル
このサービスを相談する ↗
04

具体的な業務を自動化

AIエージェント／業務自動化の開発

レポート作成や確認作業など、目的に合った自動化を Codex の仕組みで構築します。

  • 業務に合わせた手順・連携の実装
  • 成果物単位で導入
支援内容の例 ＋
  • ヒアリング → 設計 → Skills / Plugins（MCP）/ 定期タスク / GitHub 連携での実装 → テスト → 納品と使い方レビュー
  • 例: 議事録の要約と Notion / Slack への展開、CSV の集計とレポート生成、定型メールの下書き、日報・週報の登録
  • 残るもの: 実行できる Skills・設定ファイル・ソース一式、テスト結果、使用手順書、復旧手順、連携先ごとの権限一覧
  • 利用環境・地域・プランにより使えない機能があります。前提はヒアリング時に確認します
このサービスを相談する ↗
05

独自のシステムをつくる

受託開発

社内ツールから業務システムまで。要件整理から開発・運用を支援します。

  • 要件定義・設計・開発
  • 納品後の保守・改善
支援内容の例 ＋
  • 要件定義・PoC → 設計とお見積もり → 実装・テスト → リリース → 運用・保守
  • デジライズの開発体制で Codex（CLI / IDE 拡張 / cloud / Code Review）を活用して開発します
  • Codex を契約していない場合もご依頼いただけます。納品後に貴社で Codex を使う場合は環境をご相談ください
  • 残るもの: 要件定義書・設計書、ソースコード、テスト結果、引き継ぎ資料、運用・保守範囲の定義書

Codex を使うには、何が必要ですか？+

OpenAI の ChatGPT アカウントです。2026年9月時点の OpenAI 公式情報では、Codex は ChatGPT の各プランに含まれ、利用上限はプランごとに異なります。法人利用では、業務データを既定で学習に使わない設定や SSO・ワークスペース管理を備えた ChatGPT Business / Enterprise を前提に、利用できる環境（ChatGPT デスクトップアプリ・CLI・IDE 拡張・クラウド）とあわせてヒアリング時に整理します。最新の提供条件は OpenAI 公式ページをご確認ください。

プログラミング未経験でも使えますか？+

はい。日本語での依頼の仕方、途中経過と成果物の確認、承認の判断から学べます。自社の実務を題材に、作業結果の確認や安全な運用まで支援します。

研修とコンサルティングは、どう選べばよいですか？+

社員が自分で活用できる力を育てたい場合は研修、業務の整理から実装・定着まで進めたい場合はコンサルティングが適しています。課題に合わせて組み合わせることもできます。

社内の機密情報を扱う場合も相談できますか？+

はい。利用するプラン、データの保存・学習利用の条件、Codex がアクセスできるファイル・接続先・操作の範囲（sandbox と承認の設定）、社内ルールを確認し、運用を設計します。ローカルで動かす場合も、プロンプトや必要なファイルの内容は OpenAI に送信されるため、「情報が外に出ない」とは言い換えず、扱うデータの範囲から決めます。適用条件は契約・環境によって異なるため、個別に確認します。

費用はどのくらいかかりますか？+

支援範囲・人数・期間に応じて個別にお見積もりします。ご相談・お見積もりは無料です。助成金の適用可否は対象要件の確認が必要で、一律に保証するものではありません。

Claude Code など、他のツールとの使い分けも相談できますか？+

はい。デジライズは Claude Code の法人導入支援も提供しており、両方を扱う立場から、貴社の契約状況・業務・管理要件に合わせて中立に整理します。併用の設計もご相談いただけます。

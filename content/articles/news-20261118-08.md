2026年11月17日21時から11月18日8時までに確認したニュースのうち、公式発表を確認できた4件をまとめました（AI 1件、システム・開発基盤 2件、セキュリティ 1件）。
OpenAIの新モデルGPT-6.2 Astra・Sol、GitHub CopilotへのMAI Code 2の追加とコードレビューのシークレット検出、Claudeの「Appleでサインイン」の障害、Puppet Enterpriseの脆弱性のKEV追加を取り上げます。

当サイトでは、各社・各機関の公式発表を開いて内容を照合したうえで掲載しています。数字や日付は各項目末尾の出典番号から確認できます。時刻は日本時間で記載しています。

## AI

### 1. OpenAI、GPT-6.2 AstraとGPT-6.2 SolをAPIで提供開始　GitHub Copilotでも一般提供

OpenAIは2026年11月17日（米国時間）、APIの変更履歴でGPT-6.2 Astra（gpt-6.2-astra）とGPT-6.2 Sol（gpt-6.2-sol）の提供を告知しました。Astraは難度の高い推論やコーディング、Solは日常的なコーディングやエージェントの処理に使うモデルと位置づけています。どちらもResponses APIとChat Completionsに対応し、ツール呼び出しにはResponses APIが必要です [1]。
モデルページによると、どちらもコンテキストウィンドウは105万トークン、最大出力は12万8,000トークンです。100万トークンあたりの料金は、Astraが入力8ドル・キャッシュ入力0.4ドル・出力40ドル、Solが入力2ドル・キャッシュ入力0.1ドル・出力10ドルです。同日、Responses APIのバックグラウンド処理で2時間または8時間の完了枠を選べるパブリックベータも始まり、トークン料金はStandardより2時間枠で30%、8時間枠で40%低くなります [1][2][3]。
GitHubも同日、両モデルをGitHub Copilotで一般提供したと発表しました。対象はCopilot Pro+、Max、Business、Enterpriseで、利用量に応じた課金（プロバイダーの定価）となり、順次展開するとしています [4]。

**企業・担当者が確認すること：** OpenAI APIを利用している企業は、既存モデルとの料金差とGPT-6.2への移行ガイドを確認してください。Copilot Business・Enterpriseの管理者は、既定で新モデルが自動で有効になる設定のため、モデルポリシーで利用可否を確認してください [1][4]。

## システム・開発基盤

### 2. GitHub Copilotに「MAI Code 2」を追加　コードレビューのシークレット検出もパブリックプレビュー

GitHubは2026年11月17日（米国時間）、Microsoft AI（MAI）のコーディングモデル「MAI Code 2」と「MAI Code 2 Flash」をGitHub Copilotで利用できるようにしたと発表しました。MAI Code 2は大規模なデバッグや複数ファイルにまたがる実装・リファクタリング向け、Flashは説明や部分的な修正など日常の作業向けの軽量モデルです。MAI Code 2はPro、Pro+、Max、Business、Enterprise、FlashはFree、Studentを含む全プランが対象で、年額プランの対象契約者に提供し、利用量に応じて課金します [5]。
同日、Copilotのコードレビューで、公開されてしまった認証情報（シークレット）をレビューコメントで指摘する機能をパブリックプレビューとして公開しました。プルリクエストの複雑さとリスクに応じてレビューの深さを自動で選ぶ「Adaptive」なども同時に公開しています。対象はCopilot Pro、Pro+、Max、Business、Enterpriseです [6]。

**企業・担当者が確認すること：** Copilot Business・Enterpriseの管理者は、新モデルが既定で自動的に有効になるため、モデルポリシーの設定を確認してください。シークレット検出はリポジトリまたは組織の設定（Copilot → Code review）から有効にできます [5][6]。

### 3. Claude、「Appleでサインイン」が約3時間40分利用できない障害　11月18日早朝に解消

Anthropicのステータスページによると、claude.aiとClaudeのiOSアプリで、一部の利用者が「Sign in with Apple（Appleでサインイン）」でサインインできない障害が発生しました。影響は11月18日1時40分から5時20分まで（米国太平洋時間17日8時40分〜12時20分）で、6時51分に解消を告知しています。Googleアカウントとメールアドレスでのサインインには影響がなかったとしています [7]。

**企業・担当者が確認すること：** 同時間帯にClaudeへサインインできなかったという問い合わせがあった場合は、本障害の影響の可能性があります。Appleでサインインを使っている利用者には、障害時の代替手段を案内しておくと安心です [7]。

## セキュリティ

### 4. CISA、Puppet Enterpriseの脆弱性（CVE-2026-115731）を悪用が確認された脆弱性カタログに追加

米CISAは2026年11月17日（米国時間）、悪用の証拠があるとして、Perforce Puppet Enterpriseの信頼できないデータのデシリアライゼーションの脆弱性（CVE-2026-115731）を「Known Exploited Vulnerabilities（KEV）」カタログに追加しました。米国の連邦政府機関の対応期限は12月1日です [8]。
NVDの説明によると、Puppetのレポート処理に問題があり、CAが署名したエージェント証明書を持つクライアントが細工したレポートを送ることで、Puppet Server上でサービスユーザーの権限で任意のコードを実行できます。CAが十分な検証なしに証明書要求を自動署名する設定では、認証されていない攻撃者が証明書を入手できるとしています。CVSS v4.0の基本値は9.4（Critical）です [9]。

<figure><img src="/images/news/news-20261118-08/4.webp" alt="出典[8]のページ（www.cisa.gov）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [8] CISA「CISA Adds One Known Exploited Vulnerability to Catalog」2026年11月1…（www.cisa.gov・2026年11月18日 08:04 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** Puppet Enterprise・Puppet Serverを運用している企業は、Perforceのアドバイザリに従って更新・緩和策を適用し、証明書の自動署名（autosign）の設定を見直してください [8][9]。

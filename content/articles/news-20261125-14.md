2026年11月25日8時の回以降に確認したニュースのうち、公式発表を確認できた5件をまとめました（セキュリティ3件、AI1件、システム1件）。
デジタル庁の生成AI基盤「源内Web」の脆弱性、OpenSSLの4件の脆弱性、クリンスイの委託先経由の漏えい第二報、GitHub Copilotのコード補完の障害、BigQueryのAI関数の一般提供を取り上げます。

当サイトでは、各社・各機関の公式発表を開いて内容を照合したうえで掲載しています。数字や日付は各項目末尾の出典番号から確認できます。

## セキュリティ

### 1. デジタル庁の生成AI基盤「源内Web」にSSRFの脆弱性、v1.3.4で修正

JVNは2026年11月25日、デジタル庁が提供する「源内Web」にサーバサイドリクエストフォージェリ（SSRF）の脆弱性（CVE-2026-131916）があると公表しました。対象は v1.3.4 より前のバージョンで、CVSS v4.0 の基本値は5.1です。悪用されると、製品と同じネットワーク上の機器のポートの開放状態を取得される可能性があります [1]。
デジタル庁がGitHubで公開している v1.3.4（2026年10月30日公開）では、依存ライブラリの更新と、行政実務用のAIアプリに登録できるホスト名のホワイトリスト設定機能が追加され、この脆弱性に対応したとしています [2]。

<figure><img src="/images/news/news-20261125-14/1.webp" alt="出典[1]のページ（jvn.jp）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [1] JVN「JVN#78929433 源内Webにおけるサーバサイドリクエストフォージェリの脆弱性」2026年11月25日（jvn.jp・2026年11月25日 14:06 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** 源内Web（genai-web）を自組織の環境に導入している自治体・企業は、バージョンが v1.3.4 以降かを確かめてください [1]。あわせて、v1.3.4 で追加されたホスト名のホワイトリストを設定してください [2]。

### 2. OpenSSL、QUICやDANEに関する4件の脆弱性を公表、修正版は12月1日公開予定

OpenSSLプロジェクトは2026年11月24日、深刻度がいずれも「Low」の脆弱性4件のアドバイザリを公表しました。QUICの順序が入れ替わったデータの再構成でメモリを大量に使わされる問題（CVE-2026-84785）、QUICのRETIRE_CONNECTION_IDフレームの送信待ちが際限なく増える問題（CVE-2026-107494）、X.509検証でCRL配布点の名前を繰り返し組み立てる問題（CVE-2026-121482）、DANEを使うTLSクライアントがNULLポインタ参照で停止する問題（CVE-2026-84786）です [3]。
修正はGitHubの公開リポジトリに反映済みで、修正を含むリリース（4.1.1、4.0.4、3.5.10）は12月1日に公開する予定としています。DANEの問題（CVE-2026-84786）は3.0と1.1.1にも影響し、修正版の3.0.24と1.1.1zkは有償サポートの契約者だけに提供されます。JVNも11月25日にこのアドバイザリを案内しました [3][4]。

<figure><img src="/images/news/news-20261125-14/2.webp" alt="出典[3]のページ（openssl-library.org）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [3] OpenSSL「OpenSSL Security Advisory [24th November 2026]」2026年11月24日（openssl-library.org・2026年11月25日 14:06 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** OpenSSLを使うサーバーやアプリケーションを運用している企業は、使っているバージョンと、QUICやDANEの機能を使っているかを確かめ、12月1日の修正版の公開後に更新を計画してください [3]。

### 3. 三菱ケミカル・クリンスイ、委託先GoQSystemへの不正アクセスで1万466人の情報が漏えい（第二報）

三菱ケミカル・クリンスイは2026年11月24日、楽天市場、Yahoo!ショッピング、au PAY マーケットの公式ショップで受注管理に使っていたGoQSystemのシステムへの不正アクセスについて、第二報を公表しました。対象は2026年10月12日〜11月11日の注文を中心に9,894件（楽天市場7,152件、Yahoo!ショッピング2,431件、au PAY マーケット311件）、注文者とお届け先を合わせて10,466人で、同日から対象者への個別の連絡を始めました [5]。
漏えいした可能性のある情報は氏名、住所、電話番号、メールアドレス、注文内容などで、クレジットカード情報や同社の公式オンラインストアでの購入情報は含まれないとしています [5]。GoQSystemは11月13日の第二報で、問い合わせフォームの脆弱性を悪用されたもので、全体の対象は1,694社、4,367,390人と公表しています [6]。

<figure><img src="/images/news/news-20261125-14/3.webp" alt="出典[5]のページ（cleansui.com）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [5] 三菱ケミカル・クリンスイ「外部受注管理システムへの不正アクセスによるお客様情報漏えいについて（第二報）」2026年11月24日（cleansui.com・2026年11月25日 14:06 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** 受注管理などのEC業務を外部のシステムに任せている企業は、委託先から対象データの提供を受けた後の本人への連絡手順と、個人情報保護委員会への報告の準備を確かめてください [5][6]。

## AI

### 4. GitHub Copilotのコード補完と「Next Edit Suggestions」で障害、約1時間で解決

GitHubは2026年11月25日、Copilotのコード補完（Code Completions）と次の編集の提案（Next Edit Suggestions）で障害があったと公表しました。0時8分（UTC、日本時間9時8分）に調査を始め、1時5分（UTC）に対策を適用し、1時15分（UTC、日本時間10時15分）に解決したとしています。原因の詳しい分析は後日公表するとしています [7]。

<figure><img src="/images/news/news-20261125-14/4.webp" alt="出典[7]のページ（www.githubstatus.com）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [7] GitHub Status「Disruption with Code Completions and Next Edit Suggesti…（www.githubstatus.com・2026年11月25日 14:06 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** 開発でGitHub Copilotを使っている企業は、この時間帯に補完が使えなかった影響がないかを確かめ、後日公表される原因の分析を確認してください [7]。

## システム・開発基盤

### 5. BigQuery、時系列の傾向や変化点を調べるAI関数と組み込みの埋め込みモデルを一般提供

Google Cloudは2026年11月24日、BigQueryで、データの傾向（ML.TREND）、周期的なパターン（ML.SEASONALITY）、構造的な変化が起きた区間（ML.DETECT_CHANGE_POINTS）、指標どうしの相関（ML.CORRELATION）を調べるテーブル値関数を一般提供（GA）したと公表しました。クエリエディタと会話型の分析機能で使えます [8]。
あわせて、AI.EMBED と AI.SIMILARITY 関数で使う組み込みのテキスト埋め込みモデル「embeddinggemma-300m」も一般提供となりました。Databricks SQL と Apache Spark SQL をGoogleSQLに変換する移行機能はプレビューで提供しています [8]。

<figure><img src="/images/news/news-20261125-14/5.webp" alt="出典[8]のページ（cloud.google.com）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [8] Google Cloud「BigQuery release notes」2026年11月24日（cloud.google.com・2026年11月25日 14:06 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** BigQueryで売上や利用状況を分析している企業は、これまで別のツールで行っていた傾向や変化点の分析を、BigQueryの中で置き換えられるかを検討してください [8]。

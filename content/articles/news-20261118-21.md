2026年11月18日18時の回以降に確認したニュースのうち、公式発表を確認できた4件をまとめました（システム・開発基盤 1件、セキュリティ 3件）。
プレイド「KARTE」への不正アクセスの影響を公表した三菱UFJ銀行・三菱UFJ信託銀行・三菱UFJ eスマート証券とミツモア、IPAによるOracle Javaの注意喚起、GitHub CopilotでのMAI Code 2 Flashの障害を取り上げます。

当サイトでは、各社・各機関の公式発表を開いて内容を照合したうえで掲載しています。数字や日付は各項目末尾の出典番号から確認できます。時刻は日本時間で記載しています。

## システム・開発基盤

### 1. GitHub Copilot、MAI Code 2 Flashが約34分利用しにくい状態に　上流のモデル提供元の問題

GitHubは2026年11月18日、GitHub CopilotでMAI Code 2 Flashモデルの可用性が低下した障害を公表しました。18時00分ごろに調査を始め、Copilotの各製品とIDEでMAI Code 2 Flashが利用しにくい状態になっていたとしています。原因は上流のモデル提供元の問題で、提供元と連携して対応しました [1]。
18時13分ごろに緩和を確認し、18時34分ごろにMAI Code 2 Flashが再び利用できるようになったとして解決済みとしています。詳しい原因分析は、まとまり次第共有するとしています [1]。

**企業・担当者が確認すること：** 障害の間、GitHubは別のモデルか「Copilot Fusion」を選んで利用を続けるよう案内していました [1]。当サイトでは、特定のモデルに頼った開発作業について、代わりに使うモデルをあらかじめ決めておくことをおすすめします。

## セキュリティ

### 2. 三菱UFJ銀行など3社、KARTEへの不正アクセスで顧客情報の漏えいを公表　銀行は約650万件

株式会社三菱UFJ銀行は2026年11月18日、Webサイト・アプリでの顧客への案内などの業務を委託している株式会社プレイドの「KARTE」で第三者による不正アクセスが発生し、顧客の性別・年齢・居住地域（都道府県または政令指定都市）約650万件が外部に漏えいしたと発表しました。氏名、住所、電話番号、メールアドレスなど、顧客を特定できる情報や連絡のための情報は含まれていないとしています [2]。
同日、三菱UFJ信託銀行は三菱UFJ信託ダイレクトの利用者に関する会員番号を基に生成した識別子、性別などの情報約23万件 [3]、三菱UFJ eスマート証券は証券口座番号約6万件と年齢約10万5千件（互いに紐づかない状態）の漏えいを公表しました [4]。3社とも、自社のシステムが不正アクセスを受けたものではなく、現時点で本件による被害や取引への影響は確認されていないとしています [2][3][4]。

**企業・担当者が確認すること：** 3社は、本件に便乗した不審なメール・SMS・電話への注意を呼びかけています [2][3][4]。当サイトでは、KARTEを利用していた企業は、プレイドから届く漏えい範囲の報告と、自社が連携していたデータの項目を照らし合わせて確認することをおすすめします。

### 3. ミツモア、KARTE経由で氏名等を含む6万人分と識別番号・都道府県約340万人分が漏えい

株式会社ミツモアは2026年11月18日、メールマガジンやLINEの配信などに利用しているプレイドの「KARTE」が不正アクセスを受け、同サービスに連携していた顧客情報の一部が漏えいしたと発表しました。氏名、メールアドレス、電話番号、生年月日のいずれかを含む対象が60,000人、同社が会員ごとに付与している識別番号と都道府県のみの対象が3,398,469人です。パスワード、クレジットカード情報、都道府県より詳しい住所、LINE IDは含まれていないとしています [5]。
同社は11月13日にプレイドからアクセスキー漏えいの通知を受けて無効化し、11月17日に漏えいの通知を受けました。11月18日に総務省へ報告し、対象者への連絡を始めています。11月16日に公表した同社システムへの不正アクセスとは別の事案としています [5]。

**企業・担当者が確認すること：** 対象者には送信元 no-reply@meetsmore.com からメールが届きます。同社は本件を理由とするパスワード変更は必要ないとしています [5]。当サイトでは、外部サービスに連携する顧客情報を必要最小限の項目に絞り、不要な情報を定期的に削除することをおすすめします。

### 4. IPA、Oracle Javaの脆弱性対策を呼びかけ　CVE-2026-114938を含む更新プログラム（続報）

IPA（情報処理推進機構）は2026年11月18日、同日（日本時間）に公表されたOracle Javaのセキュリティ更新プログラムについて、早急な適用を呼びかけました。ネットワーク経由で攻撃を受ける可能性のある脆弱性（CVE-2026-114938）が報告されており、攻撃が行われた場合の影響が大きいとしています [6]。
対象はOracle Java SE 27.0.1.0.3、25.0.5.0.3、21.0.13.0.3、17.0.21.0.3、11.0.33.0.3、8 Update 511b33、8 Update 511b33-perfです。悪用された場合、アプリケーションの異常終了や、攻撃者によるパソコンの制御などの被害が発生するおそれがあるとしています [6]。

<figure><img src="/images/news/news-20261118-21/4.webp" alt="出典[6]のページ（www.ipa.go.jp）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [6] IPA「Oracle Java の脆弱性対策について(2026年11月)」2026年11月18日（www.ipa.go.jp・2026年11月18日 21:04 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** 社内のPCやサーバーで使っているOracle Javaのバージョンを確認し、最新版へ更新してください。商用利用ではライセンスの確認も必要です [6]。当サイトでは、Javaを組み込んだ業務アプリケーションについても、ベンダーの対応状況を確認することをおすすめします。

## セキュリティ

### 1. 「Wallet Station」不正アクセス、漏えい対象は鹿児島の決済アプリ「Payどん」　251,172件・全サービス停止（続報）

鹿児島銀行、南日本銀行、鹿児島相互信用金庫、鹿児島信用金庫の4行庫は2026年11月20日、キャッシュレス決済アプリ「Payどん」の決済システムの委託先であるインフキュリオンが第三者の不正アクセスを受け、個人情報が漏えいしたとの報告を受けたと公表しました。11月20日午前6時20分にPayどんの全てのサービスを停止しています [1]。
漏えいした個人情報は251,172件で、漏えいした可能性のある情報は、会員情報（氏名、生年月日、電話番号、性別、メールアドレス、パスワード）、決済手段（口座情報、ポイント残高、地域振興券ポイント残高）、取引履歴（取引日時、店舗名、取引金額）、加盟店情報（店舗名、電話番号）としています。11月4日に公表したメール配信の委託先（アララ）の件とは別事案で、関連はないとしています [1]。
インフキュリオンは11月21日の第3報で、11月19日の遮断以降、新たな不正アクセスは確認されておらず、漏えいした情報を用いた不正利用も確認されていないとしました。緊急点検を終えた提供先には11月21日から準備が整ったところから順次提供を再開し、点検中の提供先と漏えいの対象となった提供先への提供は停止を続けています。再開の時期は未定です [2]。

**企業・担当者が確認すること：** 4行庫は、4行庫やPayどんをかたる不審なメール・SMS・電話に注意し、記載のURLにアクセスしてログインID、パスワード、認証コード、口座情報などを入力しないよう呼びかけています [1]。当サイトでは、決済や会員管理を外部の基盤に委託している企業は、委託先で事故が起きた場合の停止判断と利用者への連絡手順を、契約と運用の両面で確認しておくことをおすすめします。

### 2. VMware vCenterに認証回避の脆弱性（CVSS 9.8）　回避策はなく修正版への更新が必要（続報）

Broadcomは2026年11月19日、VMware vCenter、VMware Tools、SDDC Managerの脆弱性5件（CVE-2026-123890〜CVE-2026-123894）を修正するアドバイザリ「VMSA-2026-0009」を公開し、11月20日に影響を受けるVMware Toolsのバージョンを明確にする更新を行いました [3]。
最も深刻なCVE-2026-123890は、vCenterのVMware Directory Serviceにおける認証回避の脆弱性で、CVSSv3の基本値は9.8（Critical）です。5件とも回避策はなく、vCenterの修正版は9.1.1.0200、9.0.2.0200、8.0 U3m、VMware Cloud Foundation 5.x向けは5.2.5です。7.0は修正版の記載がなく、延長サポート契約がある場合はBroadcomのサポートへ問い合わせるよう案内しています [3]。
このほか、SDDC ManagerのSQLインジェクション（CVSS 8.1）、認証済みのコマンドインジェクション（7.2）、ローカルでの権限昇格（6.7）と、Windows向けVMware ToolsのSAMLトークン署名回避（6.7、修正版は13.1.5.0と12.5.5）が修正されました [3]。CVE-2026-123890は、米CISAが11月20日に、実際に悪用が確認された脆弱性（KEV）のカタログに追加しています [4]。


**企業・担当者が確認すること：** 当サイトでは、vCenterを運用している企業は、バージョンが修正版に達しているかを確認し、未適用であれば優先して更新することをおすすめします。あわせて、vCenterの管理画面に到達できるネットワークの範囲が必要最小限になっているかを点検してください [3][4]。

## AI

### 3. OpenAIの主任研究者、事前学習の進み具合を数値で公開　監視技術が追いつくまで越えない「共通の上限」を提案

OpenAIのチーフサイエンティストであるJakub Pachocki氏は2026年11月22日、エッセイ「Perplexity and Intelligence」を公開しました。社内のコードベースから作った評価用データでの対数パープレキシティ（数値が小さいほど次の内容を正確に予測できることを示す指標）を示し、GPT-3.5が約0.99、GPT-4が約0.91、最近のモデルは0.8を下回り、評価の一つとしてモデルに数学の未解決問題を出してきた中で、約0.76のモデルに切り替えてから画期的な成果が出始めたとしています [5]。
同氏は、約0.68〜0.7の範囲に入るとさらに大きな能力の変化が起きると見込み、その能力が何かは分からず現在は試験していない可能性もあるとしています。早ければ2027年に事前学習の進歩が一気に進む可能性にも触れています [5]。
そのうえで、AIの振る舞いを理解・監視する能力が具体的な節目（例として、思考過程（CoT）を監視する手法の後継の開発）に達するまで、開発各社が越えないと約束する「共通の上限」を、パープレキシティなどの測定値に基づいて設けることを提案しました。これは同氏の署名記事での提案で、OpenAIとしては今後の開発ペースをめぐる共通の科学的な土台づくりへの一歩になることを望むとしています [5]。

## システム・開発基盤

### 4. Microsoft、Windows Server 2028のパブリックプレビューを開始　NVMeを既定で有効化、Server Coreの強化構成を標準に

Microsoftは2026年11月17日（米国時間）、Windows Server 2028のパブリックプレビューを開始したと公表しました。一般提供の時期やサポート期間は示していません [6]。
主な変更点として、NVMeストレージを既定で有効にし、NVMe over TCP／RDMAに対応、ReFSからの起動を可能にしました。セキュリティ面では、強化したServer Core構成を既定とし、新しいセキュリティベースラインを用意したほか、仮想マシンのブートの完全性を守るTrusted Launch、対応ハードウェアでのConfidential VMへの対応を始めています。IntuneによるWindows Serverの管理はプレビュー、Windows Admin CenterのvModeは一般提供になったとしています [6]。
自社のインフラ上でAIの推論を動かす機能は、早期アクセスプログラムを通じて一部の顧客に提供し、ハードウェア要件があるとしています [6]。

**企業・担当者が確認すること：** Microsoftは、プレビューの機能はWindows Server Insider Programで試せるとし、早期の利用や開発チームとの連携を希望する場合はWindows Server Technology Adoption Program（TAP）への申請を案内しています [6]。当サイトでは、次期サーバーOSへの移行を計画している企業は、検証環境でNVMeや既定のセキュリティ設定の変更が既存の構成に影響しないかを確かめておくことをおすすめします。

2026年11月10日18時から11月11日8時までに確認したニュースのうち、公式発表を確認できた10件をまとめました（AI 3件、システム・開発基盤2件、セキュリティ5件）。

## AI

### 1. Google、Gemini 4 Carbonを開発者・企業向けに提供開始（11月30日までは導入価格）

Googleは2026年11月10日（日本時間11月11日1時）、Gemini 4 Carbonを開発者、企業、研究者、一般利用者に提供すると公表しました。サイバーセキュリティと長時間のエージェント型の作業で最先端の性能を持つ同社の最も強力なモデルと位置づけ、大半のソフトウェア開発や知識労働にはGemini 4 Argonが引き続き適しているとしています [1]。
APIはGoogle AI StudioとGemini for businessで有料の開発者・企業すべてに提供し、価格はArgonと同じ導入価格（入力100万トークンあたり2ドル、出力100万トークンあたり10ドル）です。導入期間が2026年11月30日に終わった後は、入力100万トークンあたり4ドル、出力100万トークンあたり20ドルになります。Google AI Ultraの契約者向けには、Google Antigravity、Geminiアプリ、検索のAIモードでも順次提供します [1][2]。

<figure><img src="/images/news/news-20261111-08/1.webp" alt="出典[1]のページ（blog.google）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [1] Google「Gemini 4 Carbon is now available」2026年11月10日（blog.google・2026年11月11日 08:06 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** Gemini APIでCarbonを試す場合は、12月1日以降に単価が入力・出力とも2倍になる点を見込んで費用を見積もってください [1]。

### 2. GitHub Copilot、Gemini 4 Carbonの提供を開始

GitHubは2026年11月10日（日本時間11月11日4時26分）、Gemini 4 CarbonをGitHub Copilotで一般提供すると公表しました。対象はCopilot Pro+、Max、Business、Enterpriseの利用者で、Visual Studio Code、Visual Studio、Copilot CLI、Copilot coding agent、github.com、JetBrains IDEs、Xcode、Eclipseなどのモデル選択画面から選べます。提供は段階的に進めるとしています [3]。
料金は使用量に応じた課金で、提供元の定価で請求されます。Copilot BusinessとEnterpriseでは、管理者が既定のモデル有効化を止めているか、このモデルを個別に無効にしていない限り、自動で有効になります [3]。

<figure><img src="/images/news/news-20261111-08/2.webp" alt="出典[3]のページ（github.blog）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [3] GitHub Changelog「Gemini 4 Carbon in GitHub Copilot」2026年11月10日（github.blog・2026年11月11日 08:06 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** Copilot Business・Enterpriseの管理者は、新しいモデルを自動で有効にする設定のままでよいか、モデルポリシーを確認してください [3]。

## システム・開発基盤

### 4. GitHub、Git操作とプルリクエストで応答遅延・失敗（解決済み）

GitHubのステータスページによると、2026年11月10日16時10分（UTC。日本時間11月11日1時10分）からActionsとPull Requestsで性能低下を調査し、Git操作とプルリクエストの応答時間の増加、プルリクエストを契機とするActionsのワークフローの遅延が起きていました [5]。
17時28分（UTC）にActionsは正常に戻ったとし、17時55分（UTC。日本時間2時55分）に解決したと公表しています。詳しい原因分析は後日共有するとしています [5]。

### 5. GitHub、1年間活動のないリポジトリのDependabotアラートを12月8日から停止

GitHubは2026年11月10日、2026年12月8日から、過去1年間に活動のない大半のリポジトリでDependabotアラートをオフにすると公表しました。既存のアラートは削除せずアーカイブし、いつでも戻せるとしています [6]。
活動とみなすのは、ブランチやタグへのプッシュ、リポジトリの作成、Dependabotアラートの有効化です。プッシュすると自動で再び有効になります。Dependabotアラートを有効にするセキュリティ設定を強制しているリポジトリなどは対象外です。github.comの全プランとデータレジデンシー付きのGitHub Enterprise Cloudが対象で、GitHub Enterprise Serverには適用されません [6]。

<figure><img src="/images/news/news-20261111-08/5.webp" alt="出典[6]のページ（github.blog）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [6] GitHub Changelog「Dependabot alerts will pause on inactive repositorie…（github.blog・2026年11月11日 08:06 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** 更新は止まっていても本番で使っているリポジトリがある場合は、Dependabotアラートを有効にするセキュリティ設定を強制するなど、アラートが止まらないようにしておいてください [6]。

## セキュリティ

### 6. Microsoft、11月の月例更新を公開　Outlookのなりすましの脆弱性で悪用を確認

Microsoftは2026年11月10日（米国時間）、11月のセキュリティ更新を公開しました。このうちMicrosoft Outlookのなりすましの脆弱性（CVE-2026-124194、CVSS 6.5）は、悪用が確認されています [7]。
細工したメッセージファイルを利用者に開かせると、Outlookが通常の外部コンテンツの警告を出さずに攻撃者の管理する場所へ接続し、利用者のNTLMv2ハッシュが漏れるおそれがあります。プレビューウィンドウは攻撃経路ではないとしています。影響を受ける製品はMicrosoft 365 Apps for Enterprise、Office LTSC 2021、Office LTSC 2024です [7]。

<figure><img src="/images/news/news-20261111-08/6.webp" alt="出典[7]のページ（msrc.microsoft.com）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [7] Microsoft Security Response Center「CVE-2026-124194 Microsoft Outlook …（msrc.microsoft.com・2026年11月11日 08:06 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** Microsoft 365 AppsとOffice LTSCに11月の更新が適用されているか確認してください。CISAもこの脆弱性をKEVカタログに追加しています（項目9） [7][10]。

### 7. Google、Chrome 157の更新で悪用が確認された脆弱性を修正

Googleは2026年11月9日（米国時間）、Chromeの安定版をWindowsとMac向けに157.0.8103.50/.51、Linux向けに157.0.8103.50へ更新しました。9件のセキュリティ修正を含み、このうちXMLの解放後使用（CVE-2026-125350、深刻度High）について、悪用コードが実際に出回っていることを把握しているとしています [8]。
CISAは2026年11月10日、この脆弱性をKEVカタログに追加しました [10]。

<figure><img src="/images/news/news-20261111-08/7.webp" alt="出典[8]のページ（chromereleases.googleblog.com）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [8] Chrome Releases「Stable Channel Update for Desktop」2026年11月9日（chromereleases.googleblog.com・2026年11月11日 08:06 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** 社内のChromeが157.0.8103.50以降に更新されているか、管理コンソール等で確認してください。更新は数日から数週間かけて配信されるため、自動更新を待たずに適用を促すことも検討してください（当サイトの見解）。

### 8. Barracuda、メールセキュリティ製品などの脆弱性で一部組織への悪用を確認

Barracudaは2026年11月9日21時（米国東部時間。日本時間11月10日11時）にアドバイザリを更新し、少数の組織に影響する悪用を確認したと追記しました。対象は、認証前の認可回避（CVE-2026-116606、CVSS 9.3）とコマンドインジェクション（CVE-2026-111560、CVSS 8.6）の2件です [9]。
組み合わせて悪用されると、認可を回避して機器のroot権限を得られるおそれがあります。悪用には管理画面へのアクセスが必要です。CVE-2026-116606はEmail Security Gateway（ESG）、CVE-2026-111560はESG、Load Balancer ADC、Message Archiver、WAF Control Center、Web Application Firewall、Web Security Gatewayが対象で、修正パッチが公開されています [9]。


**企業・担当者が確認すること：** 対象製品を使っている場合は、最新のファームウェアとパッチが適用されているか確認し、管理画面をインターネットから接続できない状態にしてください [9]。

### 9. CISA、悪用が確認された脆弱性6件をKEVカタログに追加（Outlook・Chrome・Barracudaなど）

CISA（米サイバーセキュリティ・インフラストラクチャセキュリティ庁）は2026年11月10日、実際の悪用が確認された脆弱性6件をKEVカタログに追加しました。Cisco BroadWorksのXML外部実体参照（CVE-2026-20320）、Barracuda製品の2件（CVE-2026-111560、CVE-2026-116606）、Openwave Webtop Media Transcoder（CVE-2026-111793）、Microsoft Outlook（CVE-2026-124194）、Google Chromium（CVE-2026-125350）です [10]。
カタログ上の米連邦政府機関向けの対応期限は、Barracudaの2件が2026年11月13日、残る4件が11月24日です [15]。Cisco BroadWorksのアドバイザリは2026年8月19日公開で、RI.2026.07より前のリリースが影響を受けます [11]。Openwaveのアドバイザリは、1.1.22.0より前のバージョンが影響を受けるとしています [12]。

<figure><img src="/images/news/news-20261111-08/9.webp" alt="出典[10]のページ（www.cisa.gov）のキャプチャ" width="1280" height="800" loading="lazy" /><figcaption>出典 [10] CISA「CISA Adds Six Known Exploited Vulnerabilities to Catalog」2026年11…（www.cisa.gov・2026年11月11日 08:06 当サイト取得）</figcaption></figure>

**企業・担当者が確認すること：** 該当製品を使っている場合は、ベンダーの修正の適用状況を確認してください。CISAは連邦政府機関以外の組織にも、KEVカタログの脆弱性を優先して対処するよう呼びかけています [10]。

### 10. NTTデータの受託システムに不正アクセス、住友生命Vitality関連の約8万名の情報が漏えい

NTTデータは2026年11月9日、住友生命から構築・運用を受託している「住友生命Vitality体験版・企業型」「Vitalityスマート（福利厚生タイプ含む）」の申込みに係るサービスで、第三者による不正アクセスがあり、一部利用者の個人情報が外部に漏えいしたと公表しました。11月2日に不正アクセスを確認し、11月3日に外部からのアクセスを遮断してサービスを停止しています [13]。
対象は約8万名で、漏えいした情報は氏名、住所、電話番号、生年月日、メールアドレス、クレジットカード番号（一部マスキング済み）のいずれかです。カード番号が漏えいしたのは約1000名です。保険契約や歩数等のデータは含まれず、現時点で不正利用は確認されていないとしています [13][14]。


**企業・担当者が確認すること：** 福利厚生でVitalityスマートを導入している企業は、団体ポータルの利用が11月3日から停止している点を従業員に案内し、住友生命を装った連絡への注意を呼びかけてください [14]。
